# NAVIGATOR-D Project

This repository contains the code and documentation for the NAVIGATOR-D project, which focuses on developing advanced navigation capabilities for the Stretch robot platform. Updated explorer.py can find in: navigator-main/navigator_ws/explorer.py, with Log files.

## Autonomous Explorer Node for Frontier Exploration
In the [EXPLORATION_GUIDE.md](docs/EXPLORATION_GUIDE.md) will find tutorial how to start exploration alogortihm and make first steps with robot exploring autonomously! 

## ONBOARDING Guide

Please refer to the [ONBOARDING.md](docs/ONBOARDING.md) file for detailed instructions on setting up and using the Stretch 3 robot for the first time. The guide includes steps for connecting to the robot, initializing the ROS 2 environment, and controlling the robot using various methods.
